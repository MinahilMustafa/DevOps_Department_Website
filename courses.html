Academic Programs

Comprehensive curriculum designed for the modern tech landscape.

Undergraduate Courses

CS101: Introduction to Programming

Semester: Fall

Fundamental concepts of programming using Python. Covers control structures, data types, and basic algorithms.

CS202: Data Structures & Algorithms

Semester: Spring

In-depth study of arrays, linked lists, trees, graphs, and algorithm complexity analysis.

CS305: Database Systems

Semester: Fall

Relational algebra, SQL, database design, and introduction to NoSQL database management systems.

CS410: Artificial Intelligence

Semester: Spring

Core concepts of AI, machine learning basics, neural networks, and natural language processing.

CS425: Software Engineering

Semester: Fall

Software development life cycle, agile methodologies, design patterns, and project management.

CS450: Cloud Computing & DevOps

Semester: Spring

Deployment pipelines, containerization (Docker, Kubernetes), and cloud infrastructure management.
